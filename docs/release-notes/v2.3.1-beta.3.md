**A third beta of 2.3.1.** It is not the newest stable release and it does not
move `latest`: the container image is
`ghcr.io/sphings79/amberchest:2.3.1-beta.3`. Please do not run it on an archive
you cannot afford to have a problem with.

This one adds a way to find the messages the server has lost (#14), on top of the
scan change from beta 2 (#13).

Report what you find in the issue or at
https://github.com/sphings79/amberchest/issues.

---

## Messages deleted on the server are easy to recognise and to browse

With "move to _deleted" the archive keeps what vanished from the server, but
those messages were hard to tell apart and could not be browsed on their own.

- In the search and in the mailbox, a message that was deleted on the server now
  carries a "deleted on server" badge.
- The old switch "Include messages deleted on the server" is now a choice with
  three settings: leave out (the default), show along with the rest, or show
  only these. "Show only these" lists everything the server lost, across all
  folders, and the folder it came from stays visible on each row.
- The MCP search tool has a matching `only_deleted` option.
