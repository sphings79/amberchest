Back up IMAP mailboxes to plain `.eml` files you own — read-only, incremental,
with the folder tree preserved. Nothing on the server is deleted, nothing is
marked as read.

## What it does

**Backup.** Folders are opened read-only and message bodies are fetched with
`BODY.PEEK`, so the `\Seen` flag is never touched. Only new messages are
downloaded, no matter how often you run it. A message you moved between folders
on the server is moved locally instead of downloaded again — recognised from its
fingerprint before a single byte of the body is fetched. Messages that vanish go
to `_deleted/`, are kept, or are mirrored, whichever you configure per account.

**Folder selection** with checkboxes that remembers your choice. Folders that
appeared since the last run are highlighted but stay unchecked. Trash, Junk and
Drafts start unchecked, everything else is pre-selected.

**Attachment export** as a separate pass over the archive: four layouts (folder
tree, flat, year/month, one directory per message), filters for embedded images,
minimum size and file type, de-duplication by content, and a CSV/JSON manifest
that maps every file back to its message.

**Full text search** over subject, sender, body and attachment content — PDF,
Word, Excel, PowerPoint and the files inside ZIP and TAR archives are read as
well. German transliterations are indexed, so "muenchen" finds "München".

**Message viewer** that renders HTML in a sandboxed frame with external content
blocked until you ask for it, downloads the `.eml` or single attachments, and
hands the message to your mail client so you can reply.

**Export** of any search result as EML files in a ZIP, as an mbox for
Thunderbird and Apple Mail, or as one PDF per message.

**Restore** to the same account or to a different provider, with a folder
mapping proposed from the special use markers. It only ever appends: messages
already present are skipped by Message-ID.

**Docker container** with the same web interface, a built-in scheduler and
Chromium for PDF export. The desktop app can operate it remotely.

**AI access over MCP**, off by default, with a separate switch for each area:
read, back up, export, accounts, settings, delete. Passwords can be set through
it but never read.

**Optional archive encryption** with your master password, for an archive on a
disk you do not fully control.

## Installing

| Platform | File |
| --- | --- |
| macOS (Apple Silicon) | `Mail Archiver-1.0.0-arm64.dmg` |
| Windows | `Mail Archiver Setup 1.0.0.exe` or the portable build |
| Linux | `mail-archiver_1.0.0_x86_64.AppImage` or `mail-archiver_1.0.0_amd64.deb` |
| Docker | `ghcr.io/sphings79/mail-archiver:1.0.0` |

The desktop builds are **not signed**. On macOS, right-click the app and choose
*Open* on first launch; on Windows, *More info* → *Run anyway*. There is no paid
developer account behind this project.

## Security

Your IMAP credentials are stored encrypted (scrypt + AES-256-GCM) behind one
master password. **There is no recovery** — keep it somewhere safe. The desktop
app binds its server to `127.0.0.1` with a random port and a token that only
exists for that launch.
