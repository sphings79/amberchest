**A seventh beta of 2.2.0.** It is not the newest stable release and it does not
move `latest`: the container image is
`ghcr.io/sphings79/amberchest:2.2.0-beta.7`. Please do not run it on an archive
you cannot afford to have a problem with.

One small change since beta 6, for the report on #3: when the server removal
leaves a message alone because it is "not the archived message", the log now
says which side is empty, not just which field differs.

> INBOX UID 4711 is not the archived message: differs in Message-ID (empty in
> the archive, set on the server), sender (empty in the archive, set on the
> server)

The other forms are "(set in the archive, empty on the server)" and
"(different)". Dates and sizes are still shown as numbers, and still nothing
of the subject or the addresses is written.

It tells apart two causes that looked the same: an archive that holds no
message ID or sender for a message because the server gave none when it was
archived, and a server that now answers with details of another message.

Run the removal once more on a folder where messages were left alone and send
the lines that say "is not the archived message" to the issue or to
https://github.com/sphings79/amberchest/issues.
