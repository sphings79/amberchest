## A refused login shows what the server said

When the server refuses a login, the message was always the same, "Authentication
failed - check user name and password", whatever the server had answered. The
text the server sent is now added: "Authentication failed - check user name and
password (server said: ...)". A host that locks an address after too many logins,
or wants an app password, usually says so there, and that tells it apart from a
wrong password. Nothing else about the login has changed.
