## The browser no longer translates the interface

AmberChest has its own translation. A browser that translates the page as well
(Edge and Chrome offer this when the language of the page differs from yours)
rewrites the text on the page, and React then fails to update it: the page went
white, with "Failed to execute 'removeChild' on 'Node'" in the console. This
showed after "Connect again" on an OAuth account. The page is marked as not to
be translated now, and two places where text stood loose next to other elements
are wrapped, which makes the update safe even if something rewrites the text.
