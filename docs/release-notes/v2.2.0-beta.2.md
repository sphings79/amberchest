## Select several messages

The mailbox, the search results and the list of discarded messages have a
checkbox on every row. Shift-click takes everything between two rows.

A bar above the list shows how many are selected and what can be done with
them. Select the whole page and it offers **all N matches** of the current
search or filter, beyond what has been loaded: search for a sender, select
all, and throw out every newsletter from them in one go.

- **Throw out of the archive** removes the files and the index entries, the
  same as the right click menu on a single message. Nothing on the server is
  touched, and the archive remembers the decision so the next backup does not
  fetch the mail again. A confirmation names the number first.
- **Take back**, in "Discarded", works on a selection or on everything a
  filter finds. The mails come home with the next backup.

A search is worked off in batches of 500, so a hundred thousand matches show
progress, can be stopped, and do not run into a timeout. What was done stays
done if you stop.

The read-only login gets neither the checkboxes nor the calls behind them.
