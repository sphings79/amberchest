A bug fix. Nothing else changed.

## What was wrong

When adding a new account and choosing OAuth (token) as the authentication
method, the Save button stayed disabled until a password was typed in. An
OAuth account has no password, and it can only be connected to the provider
after it has been saved, so such an account could not be created at all.

## What changed

A new OAuth account can be saved without a password. Password accounts still
need one.

Thanks to the reporter of #8.
