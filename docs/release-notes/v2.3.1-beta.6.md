## Throwing out a mail that is deleted on the server leaves nothing behind

"Throw out of the archive" on a mail that is already deleted on the server now
removes it for good. It no longer shows up under "Discarded", because there is
nothing left on the server that could be fetched again.

Entries that are already in "Discarded" are cleaned up by the backup: once the
mail is gone from the server as well - or its whole folder is - the entry is
removed. This also covers mail that was thrown out first and deleted on the
server afterwards.
