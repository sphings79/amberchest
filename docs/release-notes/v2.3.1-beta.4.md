## Folder counts in the mailbox follow the deleted-mails filter

The number next to each folder in the mailbox now matches what the list shows
for the setting "Messages deleted on the server":

- **Leave out** (default): the messages the archive has, as before.
- **Show along with the rest**: those plus the ones deleted on the server.
- **Show only these**: only the ones deleted on the server. Folders without any
  show no number, so it is visible at a glance which folders are affected.

The other filters (sender, date, size) still do not change the folder counts.
