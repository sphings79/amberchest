**An eleventh beta of 2.2.0.** It is not the newest stable release and it does not
move `latest`: the container image is
`ghcr.io/sphings79/amberchest:2.2.0-beta.11`. Please do not run it on an archive
you cannot afford to have a problem with.

This one is a small change to signing in with OAuth, after #10.

What it needs from you, if "Connect again" still leaves you on a white page: the
red lines in the browser console (F12 -> Console).

Report what you find in the issue or at
https://github.com/sphings79/amberchest/issues.

---

## "Connect again" starts the sign-in

On an OAuth account, "Connect again" only opened the sign-in panel; the sign-in
began with a second click on "Sign in with a browser", and the link to open the
sign-in page again only showed after that. "Connect again" now starts the sign-in
at once when the account is saved and the provider is set up. The link stays as
a fallback if the browser blocks the new tab.

## A white page shows the error

If the interface fails while it is drawing, it showed a white page. It now shows
the error message and a button to reload.
